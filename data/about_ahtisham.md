## Project: MERIDIA Business Management and Finance System (ERP)
A freelance project for a startup client. Built with Python, SQL, pandas, PostgreSQL (Neon), SQLite, Streamlit, Plotly, ReportLab, openpyxl, the Google Gemini API, and GitHub, deployed on Streamlit Community Cloud.
Ahtisham integrated the Google Gemini API to generate plain-language summaries of business reports. The AI is given only figures the app has already calculated and is instructed not to add any numbers of its own, so summaries stay grounded in real data.
He designed a relational schema of about 19 tables and built the Python and pandas backend covering orders, inventory, costing, cash flow, and profit and loss, so data is entered once and flows through to every report.
He wrote a database abstraction layer so the same code runs on SQLite or PostgreSQL, tested it against a real PostgreSQL instance, and fixed compatibility bugs. He also built PDF and Excel export, Excel and CSV import with column mapping and duplicate warnings, and a login gate on every page.
He deployed it on Streamlit Community Cloud with a private GitHub repository, secrets management for credentials and the API key, and Neon PostgreSQL for persistent storage, after gathering requirements from the client and iterating on the design.
